# 黄金价格计算工具 - 设计文档

> 创建时间：2026-01-15

## 项目概述

开发一个黄金价格计算工具，用于计算跨境黄金套利的成本和收益。工具需要从两个网站实时爬取金价数据，结合手动输入的参数，自动计算各项成本和利润。

---

## 数据源

### 自动爬取数据（实时更新）

| 数据 | 来源 | 说明 |
|------|------|------|
| 🔵 盎司单价 (USD/oz) | https://goldprice.org/ja | 国际黄金现货价格 |
| 🔴 田中买取价格 (日元/克) | https://gold.tanaka.co.jp/index.php | 日本田中贵金属店頭買取価格 |

### 手动输入参数（黄色标记）

| 参数 | 示例值 | 说明 |
|------|--------|------|
| 补贴 | 25000 | 补贴金额（港币） |
| 港币/美金 | 7.69 | 港币兑美元汇率 |
| 水 | 10 | 交易溢价/点差（美元/盎司） |
| 减价 | 1550 | 田中交易扣除费用（日元） |
| U行情价 | 159.8 | 日元兑美元(USDT)汇率 |

---

## 计算公式

### 第一部分：补贴成本计算

```
补贴单价 (USD) = 补贴 (HKD) ÷ 港币/美金汇率
```

**示例：** 25000 ÷ 7.69 = **3.250975293** USD

---

### 第二部分：国际金价成本计算

```
水后单价 (USD/oz) = 盎司单价 + 水
每克单价 (USD/g) = 水后单价 ÷ 32.1507
```

> **注：** 32.1507 是固定常数，1公斤 = 32.1507 金衡盎司

**示例：**
- 水后单价 = 4630 + 10 = **4640** USD/oz
- 每克单价 = 4640 ÷ 32.1507 = **144.3883** USD/g

---

### 第三部分：每克总成本

```
每克单价成本 (USD/g) = 每克单价 + 补贴单价
```

**示例：** 144.3883 + 3.2510 = **147.6393** USD/g

---

### 第四部分：田中卖出收入计算

```
出货价日元 = 田中买取价格 - 减价
田中单价 (USD/g) = 出货价日元 ÷ U行情价
```

**示例：**
- 出货价日元 = 25931 - 1550 = **24381** 日元
- 田中单价 = 24381 ÷ 159.8 = **152.571965** USD/g

---

### 第五部分：利润计算

```
每克利润 (USD) = 田中单价 - 每克单价成本
```

**示例：** 152.57 - 152.43 = **0.14** USD/g

---

### 第六部分：每公斤利润计算 (公式已确认)

右下角的两个数值：

| 数值 | 计算公式 | 说明 |
|------|----------|------|
| **141.6368577** | `(田中单价 - 每克总成本) × 1000` | **每公斤美元毛利**<br>计算依凭：`(152.571965 - 152.430328) × 1000`<br>*(注：客户截图中的 152.433281 为笔误，实际应为 152.430328)* |
| **22633.56985** | `141.6368577 × U行情价(159.8)` | **每公斤目标货币毛利** (如日元) |

### 前端框架选择分析

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **Vite + Tailwind** | 轻量快速、开发体验好、构建优化 | 需要构建步骤 | ⭐⭐⭐⭐⭐ **推荐** |
| Next.js | 功能强大、SSR支持 | 对于简单工具过于复杂 | ⭐⭐⭐ |
| 纯 HTML + Tailwind CDN | 最简单、无需构建 | Tailwind 功能受限、文件较大 | ⭐⭐⭐ |
| Astro | 静态优先、性能好 | 学习曲线、社区较小 | ⭐⭐⭐⭐ |

### 推荐方案：Vite + Tailwind CSS v4

**选择理由：**

1. **Vite 优势**
   - ⚡ 极速热更新 (HMR)
   - 📦 优化的生产构建
   - 🛠️ 零配置开箱即用
   - 🔌 丰富的插件生态

2. **Tailwind CSS v4 优势**
   - 🎨 现代化的原子类样式
   - 🌙 内置暗色模式支持
   - 📱 响应式设计简单
   - ✨ 丰富的动画和过渡效果
   - 🗜️ 自动 Tree-shaking，生产包很小

3. **UI 设计风格**
   - 玻璃拟态 (Glassmorphism) 卡片效果
   - 渐变背景
   - 柔和阴影
   - 微交互动画
   - 暗色/亮色主题切换

### 技术栈

## 部署方案分析

### 方案对比

| 平台 | 静态前端 | 后端服务 | 爬虫支持 | 免费额度 | 推荐度 |
|------|----------|----------|----------|----------|--------|
| **Vercel** | ✅ 优秀 | ✅ Serverless Functions | ⚠️ 有限制 | 100GB/月 | ⭐⭐⭐⭐ |
| **Railway** | ✅ 支持 | ✅ 完整Node.js | ✅ 完整支持 | $5/月额度 | ⭐⭐⭐⭐⭐ |
| **Render** | ✅ 支持 | ✅ 完整Node.js | ✅ 完整支持 | 750小时/月 | ⭐⭐⭐⭐ |
| GitHub Pages | ✅ 优秀 | ❌ 不支持 | ❌ 不支持 | 无限 | ⭐⭐ |
| **Cloudflare Workers** | ✅ 优秀 | ⚠️ 有限制 | ❌ 不支持 | 100k请求/天 | ⭐⭐⭐ |

### 推荐方案：Vercel + API Routes

**原因：**

1. **Serverless Functions 支持**
   - 可以在 `/api` 目录下创建爬虫 API
   - 自动扩缩容，无需管理服务器

2. **部署简单**
   - 连接 GitHub 仓库后自动部署
   - 每次 push 自动更新

3. **免费额度足够**
   - 个人项目完全免费
   - 100GB 带宽 + 100小时函数执行时间

4. **技术架构**
   ```
   vercel-project/
   ├── index.html          # 主页面
   ├── css/style.css
   ├── js/main.js
   └── api/
       ├── goldprice.js    # Serverless 爬虫
       └── tanaka.js       # Serverless 爬虫
   ```

### 备选方案：Railway

如果 Vercel 的 Serverless Functions 无法满足 Puppeteer 爬虫需求（内存/时间限制），可以使用 Railway：

- 完整的 Node.js 服务器环境
- 支持 Puppeteer 无头浏览器
- 每月 $5 免费额度
- 部署同样简单

### 不推荐 GitHub Pages

GitHub Pages 只支持静态网站，无法运行后端代码。由于本项目需要爬取外部网站数据，必须有后端服务支持，因此 GitHub Pages **不适合**此项目。
