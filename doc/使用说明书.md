# 黄金价格计算工具 - 功能介绍与使用说明书

## 1. 产品简介
本工具是一款专为黄金买取业务定制的高精度金融计算器。它能够实时获取国际金价和 Tanaka（田中贵金属）回收价，结合汇率、补贴、水费等多种参数，一键计算出精准的套利成本、每克利润及综合收益。

本工具采用纯前端架构，所有数据仅存储在您的设备本地，确保商业机密的安全，同时支持电脑与手机端完美适配，满足随时随地的业务需求。

---

## 2. 核心功能

### 📊 实时行情监控
*   **国际金价 (GoldPrice.org)**：实时同步最新的国际黄金现货价格 (USD/oz)。
*   **田中回收价 (Tanaka)**：实时获取田中贵金属的官方回收报价 (JPY/g)。
*   **智能刷新**：支持一键刷新最新数据，确保计算基准的准确性。

### 💰 多维度利润核算
*   **高精度成本模型**：内置复杂的成本计算公式，涵盖补贴 (HKD)、“水” (Premium)、汇率损耗等多重变量。
*   **双币种利润展示**：同时计算美元 (USD) 和日元 (JPY) 的毛利。
*   **盈亏直观提示**：
    *   **绿色**：盈利状态，清晰展示利润率。
    *   **红色**：亏损预警，避免错误交易。

### 📝 历史记录与导出
*   **自动保存**：每次点击“开始计算”，系统自动保存当前的所有输入参数及计算结果。
*   **本地存储**：历史记录保存在浏览器本地，不上传服务器，保护隐私。
*   **Excel/CSV 导出**：支持一键导出历史记录为 CSV 表格，文件名包含精确时间戳（如 `gold_price_history_20260116_1230.csv`），方便财务对账和复盘。

### 📱 极致的用户体验
*   **苹果风格设计 (Apple-Style)**：极简、现代的 UI 设计，磨砂玻璃质感，操作流畅。
*   **响应式布局**：
    *   **电脑端**：双栏布局，左侧输入，右侧即时看结果，无需滚动。
    *   **手机端**：自动适配屏幕，单手操作友好，适合外勤业务场景。

## 3. 使用指南

### 第一步：获取实时数据
1.  打开工具页面。
2.  点击左上角的 **“刷新”** 按钮。
3.  系统将自动抓取最新的 **国际金价 (USD)** 和 **田中回收价 (JPY)**。

### 第二步：设置计算参数
在左侧的“参数设置”面板中输入您的业务参数：

| 参数名称 | 说明 | 示例值 |
| :--- | :--- | :--- |
| **补贴 (HKD)** | 供应商提供的每公斤港币补贴金额 | `25000` |
| **汇率 (HKD/USD)** | 当前港币兑美元的汇率 | `7.69` |
| **水 (USD/oz)** | 溢价或手续费（每盎司美元） | `10` |
| **减价 (JPY)** | 田中价格基础上的扣减金额（日元） | `1550` |
| **U 行情价** | USDT 对日元的兑换汇率 | `159.8` |

> **注意**：部分参数会自动记忆上次输入的值，无需重复填写。

### 第三步：查看计算结果
点击底部的 **“开始计算”** 按钮，右侧面板将即时显示：

*   **每克利润 (USD)**：最核心的盈利指标。
*   **盈亏百分比**：投资回报率参考。
*   **每公斤毛利**：
    *   **USD**：每公斤总美元毛利。
    *   **JPY**：每公斤总日元毛利 (基于 U 行情价换算)。
*   **成本/收入明细**：
    *   每克总成本 (包含补贴和水费)。
    *   田中折算美元单价。

### 第四步：管理历史记录
1.  即时查看：页面下方“历史记录”列表会显示最近的操作记录。
2.  **导出表格**：点击列表右上角的 **“导出 CSV”** 按钮，即可下载数据文件。
3.  **清空记录**：如需重置，可点击“清空”按钮。

## 4. 特别说明
*   **数据隐私**：本工具不收集任何用户输入的数据，所有计算均在您的浏览器内完成。
*   **离线使用**：在加载页面后，即使断网（不刷新实时数据的情况下），依然可以使用计算和历史记录功能。
